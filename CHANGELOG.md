# Changelog

Заметные изменения `dev.avar.me`. Формат — по дате коммита, в обратном хронологическом порядке.

## 2026-10-28

- fix: `ɫ`/`ł`/`ɬ` снова транслитерируются как лӀ (не лъ) — откат предыдущего фикса, лъ/лӀ разные латеральные
- fix: акцентированные латинские гласные (á é í ú è — ударение у Жиркова) протекали буквами прямо в кириллицу (`burtábi` → `буртáби`); теперь гласная + U+0301, как и всюду на сайте
- feat: подхвачена унификация sources для av-ru.1936 — новые канонические буквы `ⱬ`→цӀ, `ƣ`→гъ, `ꝗ`→кь, `ꞩ`→ц, `ƶ`→ж; старые шумные OCR-варианты (ṣ/ẓ/ɫ/ɬ/ḷ/ɭ/ơ) оставлены в таблице для совместимости
- fix: `ł`/`ɫ`/`ɬ` теперь лъ (не лӀ) — старое разделение было основано на варианте `ɫ`, который sources уже устранили при унификации
- fix: `x` с седилью/огонэком/запятой снизу (словарь Жиркова, 1936) транслитерировался как хъ, должно быть хь (напр. `rox̧` → рохь «лес»); подтверждено sources по сверке с оригиналом
- fix: `ħ` транслитерировался как хь, должно быть хӀ (словарь Жиркова, 1936)
- fix: `__ASSET_VERSION__` считался по данным только dict_av (`av-ru`) — смена данных в доп. словаре (напр. av-ru.1936) не меняла кэш-бастинг; теперь учитываются все словари сайта
- fix: `__ASSET_VERSION__` (кэш-бастинг `?v=` для `app.js`/`styles.css`/`phrases.js`) считался только по хэшу словарных данных — деплой, меняющий только код без данных, не менял `?v=`, и CDN продолжал отдавать старый закэшированный `app.js` под тем же адресом (так и было с этим самым деплоем). Теперь `__ASSET_VERSION__` = хэш(данные + код шаблонов); `build_id` внутри `manifest.json` не трогали — он как и раньше только про данные
- feat: третий словарь в переключателе — `av-ru.1936` (Аварско-русский словарь Л. И. Жиркова, 1936), первым по порядку и по умолчанию; латиница Жиркова транслитерируется в кириллицу при сборке (`src/translit_1936.py`). Однонаправленный (авар → рус), без TMA и без `/phrases`
- tweak: переключатель словарей на главной теперь строится из `SITE.dicts` в рантайме (раньше — две захардкоженные кнопки), поддерживает произвольное количество словарей

## 2026-09-17

- tweak: ударение в заголовке статьи показывается знаком акута (´) над гласной; в формах слова — как раньше, цветом и подчёркиванием
- feat: омонимы (одно `word`, разные части речи/значения из разных строк jsonl) больше не сливаются в одну статью — каждый рендерится своей карточкой под общим `#word=`, со своими переводом, формами, ударением

- fix: ударение в формах слова считалось только по основе (`stem`), поэтому пропадало, если ударная буква попадала в суффикс (напр. «бахьи» с основой «б»)
- fix: при слиянии омонимов (одно `word`, разные части речи) ударение брало значение только первого из них и применялось ко всем формам — теперь у каждого омонима своё `stress`/`stem` (напр. «бахьи»-масдар и «бахьи»-существительное отличаются)
